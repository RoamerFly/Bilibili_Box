BiliBox 新手使用教程
====================

一、安装程序
1. 打开 GitHub 发布页：https://github.com/RoamerFly/Bilibili_Box/releases/latest
2. 按系统下载：
   Windows：优先下载 windows-x64-installer.exe；不想安装可下载 portable.zip。
   macOS：Apple 芯片下载 macos-arm64，Intel 芯片下载 macos-x64。
   Linux：Ubuntu/Debian 下载 .deb，Fedora/RHEL/openSUSE 下载 .rpm，其他发行版可用 AppImage。
3. Windows 双击安装包即可。macOS 首次打开若提示无法验证开发者，请到“系统设置 → 隐私与安全性”选择“仍要打开”。
   Linux AppImage 需要先给文件执行权限，再双击运行；也可以右键选择“允许运行”。

二、第一次打开
1. 在左侧进入“设置 → 登录”，使用扫码登录或内置浏览器登录 Bilibili。
2. 登录后再下载，会员、课程、高清画质等内容需要当前账号拥有对应权限。
3. 到“设置 → 下载目录”选择保存位置。不设置时会使用程序默认的 download 文件夹。

三、首次下载前安装媒体处理环境（推荐）
1. 打开“设置 → 媒体处理环境 (FFmpeg)”。
2. 点击“下载安装”，等待下载、解压和自检完成，状态变为“已就绪”。
3. 也可以选择本机已有的 ffmpeg/ffmpeg.exe；ffprobe/ffprobe.exe 放在同一目录即可。

注意：当前版本不会在点击下载时静默安装 FFmpeg。没有 FFmpeg 时，单独的视频流可能仍能下载，但需要音视频合并、MP3 转换或 AI 音频转录的任务会失败，并提示先安装运行环境。应用内一键安装支持 Windows、macOS 和 Linux，安装时需要网络；下载失败可先检查代理，或手动选择本地路径。

四、搜索、播放和下载
1. 在“聚合搜索”输入关键词、BV 号、完整视频链接，或粘贴 b23.tv 分享链接。
2. 选择“视频、番剧、影视、直播、专栏、课程”等分类，打开结果即可播放。
3. 播放页点击“下载”或分集列表右侧的下载按钮，选择清晰度后开始任务；“下载所有”可加入全部分集。
4. 下载进度会显示在底部悬浮胶囊和“下载列表”中。失败项可以点击“重新下载”。
5. “我的课程”用于查看已购课程；课程需要登录并拥有观看权限，支持直接播放和下载。

五、常用播放快捷键
空格：播放 / 暂停（先点击播放器或按 Tab 让播放器获得焦点）。
F：进入或退出全屏；Esc：退出全屏。
左右方向键：短按后退 / 前进 5 秒；长按按住时以 3 倍速向后 / 向前播放。
上下方向键：降低 / 提高音量。

六、AI 总结（可选）
1. 在“设置 → AI 设置”添加一个 AI 供应商，填写 Base URL、API Key。
2. 点击“获取模型”，从服务端返回的模型列表中选择模型并保存。
3. 打开视频播放页，点击右上角“AI 总结”。已有字幕会优先使用；没有字幕时会尝试本地音频转录，因此必须先安装 FFmpeg，并正确配置本地转录模型。

七、后台下载
在“设置 → 关闭窗口时”选择“最小化到托盘运行”，关闭窗口后下载不会中断；从系统托盘菜单可重新打开窗口或退出程序。

八、常见问题
1. 下载失败并提示 FFmpeg：回到“设置 → 媒体处理环境”，点击“下载安装”，完成后重试。
2. 提示登录、权限或 412：重新登录，降低请求频率，稍后再试，或在“设置 → 网络代理”配置可用代理。
3. 视频只有声音或 MP4 无法播放：删除该失败文件，确认 FFmpeg/FFprobe 已就绪后点击“重新下载”。
4. 保存失败或找不到路径：把下载目录改到一个存在且有写入权限的文件夹，不要使用只读目录或已拔出的移动磁盘。
5. 课程打不开：确认当前账号已购买或获得课程权限，并先在 Bilibili 网页端确认可以正常观看。

最后提醒：请遵守 Bilibili 用户协议、版权规则和当地法律法规，只下载你有权保存和使用的内容。
