## 新版本内容

本版本重点完善内容详情页、播放器操作和 Windows 构建稳定性。

### 新增与优化

- 专栏详情现在按照原文顺序混排文字、图片和图片说明，并恢复顶部横幅、标题、作者与所属文集的正确层级。
- 完善番剧、影视和专栏详情页的评论区，支持展示主评论及回复内容。
- 优化播放器画质与倍速菜单的弹出方向，在窗口空间有限时也能完整选择。
- 更新项目 README 与非商业用途许可证说明。

### 修复的问题

- 修复专栏文字集中在顶部、图片集中在底部以及图片说明位置错误的问题。
- 修复旧专栏头图字段为空时顶部背景图缺失、封面被错误追加到正文末尾的问题。
- 修复从搜索结果进入番剧、影视或专栏后评论区缺失，以及部分专栏评论始终为空的问题。
- 修复通用播放页的画质、倍速选择菜单被播放器边界遮挡的问题。
- 修复 Windows 构建时 Rollup 文件被占用导致 `npm ci` 失败，随后继续构建并提示找不到 `tsc` 的问题。
