## 新版本内容

### 新增与优化

- 全面更新 Windows、macOS 与 Linux 构建脚本：统一使用锁定依赖、复用仓库内应用图标，并改进 FFmpeg/FFprobe 运行时准备、产物检查和失败提示，提升本地构建及 GitHub Actions 发布的稳定性。
- 重构聚合搜索体验：视频、番剧、影视、直播、专栏与用户分类拥有独立分页状态，切换某一分类页码不再影响其他栏目；搜索条件、分类页码及上次结果支持持久缓存，重新进入页面后可继续浏览。
- 新增可选网页搜索兜底：官方 API 触发 412 风控时保留当前结果，并由用户主动选择使用 B 站公开网页搜索或在系统浏览器中打开，不会在后台自动切换来源。
- 扩展网页搜索结果解析：支持服务端 HTML 中的视频、直播、用户、番剧、影视和专栏结果，增加独立缓存、来源标识、异常页面识别及解析测试。
- 完善搜索结果作者信息：视频、直播与专栏卡片统一显示可点击的小型 UP 主头像；缺失头像时按 UP 主编号补查资料，并对有效头像进行持久缓存和请求去重。
- 优化下载文件命名和目录处理：下载内容优先使用作品发布标题作为保存名称，自动清理 Windows 不支持的文件名字符，并在创建媒体文件前完整建立目标目录。
- 优化下载交互：通用播放页分 P 列表新增“下载所有”和单集下载按钮；清晰度弹窗重新调整标题、控件和操作区布局，并默认选中设置中的下载清晰度。
- 精简下载日志：分片下载过程中不再持续输出带标题和百分比的重复日志，仅保留开始下载、下载完成及明确错误原因等关键状态。
- 重新设计悬浮下载栏：保留当前悬浮胶囊结构，统一亮色与暗色配色、边框、阴影和状态反馈，使其与应用整体视觉风格一致。
- 完善主题系统：补齐左侧导航栏、左下角账号区域、文本、滚动条、弹窗、卡片及窗口左上角区域的亮暗色适配，降低滚动条视觉干扰。
- 优化页面性能和视觉稳定性：恢复常用页面缓存，减少重复请求与重新挂载；收敛页面切换动画和布局变化，改善下载队列分类切换时的卡片抖动。
- 统一多页面紧凑布局：优化主页、推荐、搜索、收藏、稍后再看、历史、下载、设置和 UP 主主页的边距、卡片密度及多选工具栏样式。

### 修复的问题

- 修复 Windows 前端构建中的 Select 组件类型错误，包括不支持的 `disabled` 属性、数字子节点以及字符串数组子节点导致的 TypeScript 编译失败。
- 修复下载保存名称偶尔退化为 `lv_0_时间戳`，未采用作品真实标题的问题。
- 修复下载时因目标父目录未创建、标题包含非法路径字符或相对路径解析不完整而出现“创建文件失败：系统找不到指定的路径 (os error 3)”的问题。
- 修复聚合搜索页面离开或重新进入后，上次关键词、筛选条件、分类页码和搜索结果丢失的问题。
- 修复综合搜索各分类共用分页状态，跳转视频页码会连带影响专栏等其他分类的问题。
- 修复搜索 API 返回空头像后被永久写入缓存，网络恢复后仍无法重新补查真实头像的问题。
- 修复搜索结果同时补查大量 UP 主资料时产生请求拥塞的问题，现改为排队请求并复用内存及持久缓存。
- 修复聚合搜索卡片缩放后生成小数 CDN 裁剪参数，导致真实头像请求返回 HTTP 400、所有用户均显示同一占位图标的问题。
- 修复头像图片加载失败后仅隐藏图片、不尝试刷新 UP 主资料的问题，并补齐普通视频卡片遗漏的 UP 主编号参数。
- 修复亮色主题下窗口左上角出现与导航栏不一致的白色缺口，以及暗色主题下导航栏、账号区域和部分文字未切换颜色的问题。
- 修复右侧滚动条颜色固定、过于醒目且不随亮暗主题变化的问题。
- 修复下载队列在“全部”“下载中”等分类之间切换时，动画与滚动条宽度变化引起的卡片位移和页面抖动。
- 修复下载清晰度弹窗首次打开为空选状态、控件对齐不自然，以及亮暗主题下层级不清晰的问题。
- 修复多个平台构建脚本依赖安装方式不一致、Windows 构建失败时退出码显示为空，以及发布产物缺少必要运行时检查的问题。
