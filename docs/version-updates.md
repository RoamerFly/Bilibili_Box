## 新版本内容

### 新增与优化

- 聚合搜索与链接解析：默认搜索类型变更为“综合”，移除多余的搜索按钮；搜索框支持直接粘贴直播间、用户空间等链接并自动解析直达。
- 新增页面：新增图文动态页、评论区展示、UP主主页（含投稿及动态）、关注动态、我的点赞等全新页面。
- 界面优化：优化卡片布局显示，主页功能卡片优化更新；初始启动窗口模式默认全屏最大化。
- 交互功能新增：新增投币交互动画；支持 UP 头像点击交互，新增点赞、投币、收藏、一键下载全部功能。
- 设置与缓存：设置页新增“清空页面缓存”、“查看缓存”、“切换多账号登录”、“是否显示评论区”等高级选项。
- 风控机制升级：底层请求全面引入无头与溯源验证策略，静默绕过 412 拦截，大幅减少手动验证弹窗。
- 工作流与更新：优化 Release 工作流，自动生成安装包签名文件并上传；更新自动发布流程，增加私钥签名验证。

### 修复的问题

- 修复了部分推荐分区无法正常显示的问题。
- 修复了页面跳转返回后丢失状态的问题。
- 修复了“推荐/关注动态”中手打中文搜索与默认排序逻辑不一致的问题。
- 修复了通用播放页评论区头像和右上角 UP 主入口跳转报错的问题。
- 修复了部分页面点赞、投币操作时因 Cookie 未及时同步导致的非法访问报错。

### 界面与体验

- 平衡播放器点赞、投币、收藏、分享图标尺寸和间距。
- 调整动作栏宽度，使其与视频区域左右边界对齐。
- 调整“搜索”主按钮尺寸与间距，使其与左侧下拉分类框完美对齐。
- 完善通用播放页布局，全面变更为上标题、下简介的直观排列模式。
