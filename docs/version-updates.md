## 新版本内容

本版本在 `v1.0.5` 基础上重点更新了界面主题、下载体验和聚合搜索。

### 新增与优化

- 下载栏改为更轻量的悬浮胶囊，并重新调整亮色、暗色下的配色、边框和阴影。
- 完善全局亮暗主题，侧边栏、账号区域、滚动条、弹窗和卡片现在会统一切换外观。
- 播放页的分 P/剧集列表支持单集下载和下载所有；下载清晰度弹窗会默认选中设置中的清晰度。
- 聚合搜索支持保留上次结果和筛选状态，各分类可独立翻页；搜索结果补充 UP 主头像。
- 官方搜索触发 412 风控时，可由用户主动选择网页搜索兜底，并保留已有搜索结果。
- 优化常用页面缓存、切换动画和卡片布局，减少重复加载、页面卡顿与界面抖动。

### 修复的问题

- 修复下载文件偶尔使用 `lv_0_时间戳` 命名，以及目标目录不存在时提示“系统找不到指定的路径”的问题。
- 修复搜索结果头像全部显示为相同占位图、重新进入搜索后结果丢失，以及不同分类页码相互影响的问题。
- 修复暗色模式下侧边栏和部分文字未适配、亮色模式左上角出现白色缺口，以及滚动条过于醒目的问题。
- 修复播放页剧集较多时卡片被强制压缩、标题文字重叠的问题；长标题现在会自适应撑高卡片。
- 修复下载队列切换“全部”“下载中”等分类时卡片位移和抖动的问题，并精简重复的分片进度日志。
- 修复 Windows 前端构建的 TypeScript 报错，并提升 Windows、macOS、Linux 构建与发布产物的稳定性。
