## 新版本内容 (v1.2.1)

### 新增与优化

- **独立解耦 FFmpeg 运行环境**：
  - 参考同系解耦方案，将 FFmpeg/FFprobe 二进制工具与安装包本体彻底分离，安装包体积由 ~104MB 骤降至 ~20MB，日常更新不再重复下载大体积多媒体工具。
  - 设置中心新增「FFmpeg 运行环境」独立管理面板，清晰展示当前就绪状态、版本及路径来源（自定义路径 / 独立持久化环境 / 内置环境 / 系统 PATH）。
  - 支持应用内一键下载解压与版本自检，带实时下载进度、下载速率与阶段通知；亦支持手动选择本地已有 FFmpeg 路径。
- **新增网络代理配置支持**：
  - 设置中心「常规设置」中新增「网络代理」配置项，支持自由切换「系统代理」、「不使用代理」与「自定义代理」。
  - 自定义代理支持输入常见代理地址（如 `http://127.0.0.1:7890` 或 `127.0.0.1:7890`），保存后即时重载底层网络客户端，无需重启应用。
- **设置项说明文本视觉升级**：
  - 移除设置项标题下方占位的副标题文本，升级为标题右上角的精美圆形 `(i)` 信息小图标。
  - 鼠标悬浮或点击时展开轻量气泡提示框，展示详细功能说明，点击外部区域自动收起，使整个设置页面更加紧凑、整洁、清爽。

### 修复的问题

- 修复自动更新器在校验 minisign 签名时因 Base64/明文格式差异导致 `更新包签名格式无效: Invalid encoding in minisign data` 的问题，双向兼容标准 minisign 明文格式与单行 Base64 编码签名。
- 更新打包与发布工作流，发布时独立打包与签名 `ffmpeg-runtime-windows-x64.zip`。

## 新版本内容 (v1.2.0)

### 新增与优化

- **全新评论区 AI 智能回复助手**：
  - 视频与动态评论区新增专属「AI 回复」入口，智能结合当前视频主题与上下文回复链生成自然、高情商的回复。
  - 全局单个回复框单例互斥控制，支持普通回复与 AI 回复无缝平滑切换，再次点击可即时收起。
  - 支持一键快捷填入输入框、一键复制到剪贴板与换一换重新生成。
- **全新轻柔弹性折叠侧边栏导航**：
  - 支持在 210px 完整导航与 64px 极简纯图标导航之间随心切换，为主内容区腾出更多视野。
  - 采用物理弹簧动效（Spring Animation），展开与收起顺滑灵动、轻柔自然。
  - 32px 绝对对齐防抖动架构，展开收起过程中所有图标水平位置恒定不动，完全消除跳跃感。
  - 彻底修复此前展开状态下窗口拖拽条越界遮挡折叠按钮导致无法点击的问题。
- **全局界面与布局实时等比缩放引擎**：
  - 接入底层原生缩放引擎，拖动滑块即可 60fps 实时预览，无需刷新或重启。
  - 穿透全站所有内联样式与组件，字号、行高、卡片尺寸、边距与网格布局同步等比扩展，大字号下不溢出不破损。
  - 支持 11px ~ 22px 连续无级调节、`[ A- ]` / `[ A+ ]` 可点击微调按钮、精确数字输入与「默认 (14px)」一键还原。
  - 导航栏字号自适应保持约 105% 正文倍率，始终清晰饱满，永不小于内容区。
  - 设置项布局防挤压自适应改造，极端大字号或小窗口下说明文本依然宽敞易读。
- **设置中心全面重构**：
  - AI 设置增加功能分区子 Tab（「AI 总结」与「AI 回复」），模型配置升级为顶栏常驻大弹窗按钮。
  - 「AI 总结」梳理为「提示词设置」与「本地语音转录」可折叠卡片，默认折叠收起，大幅收紧垂直空隙。
  - 退出确认弹窗支持「记住此选项」，开启每次询问时可直接勾选记住，免去重复确认。
  - 新增「关于」项目入口，一键直达 GitHub 开源主页；优化清理缓存文案为「清空页面缓存」。

### 修复的问题

- 修复清晰度与倍速下拉选择器在部分极端场景下首次渲染显示为空白的问题。
- 修复全屏视口贴合尺寸，彻底消除任意缩放比例下的异常水平溢出或滚动条。
- 全量路由组件引入 React Suspense 懒加载与 ErrorBoundary 异常隔离保护，单模块异常不影响全局并支持一键恢复。

## 下载建议

- Windows 安装版（推荐大多数用户）：下载 `Bilibili_Box-v*-windows-x64-installer.exe`
- Windows 便携版（免安装）：下载 `Bilibili_Box-v*-windows-x64-portable.zip`，解压后运行里面的 `Bilibili_Box.exe`
- macOS Apple Silicon / M 系列：下载 `Bilibili_Box-v*-macos-arm64-installer.dmg`
- macOS Intel：下载 `Bilibili_Box-v*-macos-x64-installer.dmg`
- Linux Debian/Ubuntu：下载 `Bilibili_Box-v*-linux-x64-installer.deb`
- Linux Fedora/openSUSE/RHEL：下载 `Bilibili_Box-v*-linux-x64-installer.rpm`
- Linux 通用 AppImage：下载 `Bilibili_Box-v*-linux-x64-appimage.AppImage`
- Linux 通用便携：下载 `Bilibili_Box-v*-linux-x64-portable.tar.gz`

Linux 应用内自动更新仅支持已验签的 AppImage；Deb/RPM 请使用系统包管理器或手动安装。`.sig` 和 `latest.json` 主要用于自动更新与签名校验，普通安装通常不需要手动下载。
