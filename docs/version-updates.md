# Bilibili Box 版本更新记录

## v1.0.5

### 新增与优化

- 设置页新增“清空页面缓存并更新所有页面”，执行时锁定页面并显示加载动画，完成后提示刷新成功。
- 设置页新增“查看缓存”，可查看页面缓存和下载缓存的文件数量、目录大小与路径。
- 设置页新增“切换账号”，支持在已保存的多个账号数据目录之间切换。
- 设置页新增“是否显示评论区”，可按需打开或关闭视频详情与动态详情的评论区。
- 发布流程默认读取本文件作为 GitHub Release 正文内容来源，便于每次版本发布复用。

### 修复

- 修复“推荐/关注动态”搜索框手打中文与复制粘贴中文筛选结果不一致的问题。
- “关注动态”页隐藏不适用的默认排序按钮，保留刷新、搜索和多选下载能力。
- 统一多选按钮逻辑：“全选当前 / 多选 / 下载选中”固定顺序展示，多选开启后按钮变为“取消”。
- 通用播放页右侧信息卡新增 UP 主入口，评论区头像也可点击进入 UP 主页面。
- 通用播放页布局调整为标题在播放器上方、简介在播放器下方。

## v1.0.4

### 新增与优化

- 新增视频点赞、投币、收藏后的按钮原位浮动提示。
- 新增 GitHub Releases 自动更新元数据 `latest.json`，支持签名安装包分平台更新。
- 优化投币弹窗雪碧图动画，选中后按 24 帧逐帧播放。

### 修复

- 修复点赞、投币接口因 Cookie 合并异常导致的账号异常和非法访问问题。
- 修复收藏弹窗选择与取消收藏后的状态反馈。
- 平衡播放页点赞、投币、收藏、分享图标尺寸与间距。
